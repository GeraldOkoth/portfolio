## Performance Optimization Journey

This portfolio has been progressively optimized as part of my development and learning journey.

### **Create React App → Vite**

The project was originally built using Create React App and was later migrated to Vite.

The migration simplified the build setup and provided a faster modern development and production build workflow.

### **Dependency Cleanup**

Unused and unnecessary dependencies were identified and removed from the project.

This included packages that were not being used by the frontend application.

### **Code Splitting & Lazy Loading**

Pages and components were progressively split into separate chunks so that users do not have to download the entire application upfront.

### **Image Optimization**

Large images were identified and optimized.

For example, the original profile image was approximately:

`13.2 MB`

and was reduced to approximately:

`171 KB`

The About page image was also reduced from approximately:

`4.5 MB`

to approximately:

`199 KB`

Additional image optimization and lazy loading improvements remain part of the ongoing optimization process.

### **Performance Auditing**

The deployed portfolio has been evaluated using:

* Chrome Lighthouse
* Google PageSpeed Insights

The audit results are being used to identify further improvements rather than optimizing blindly.
